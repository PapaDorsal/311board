# Rebuilding the street layer

`data/streets.geojson` (the arterial lines and labels on the ward map) is
generated by `tools/prep-streets-geo.mjs`. That script is fully
self-contained and re-downloads its source automatically — this note exists
only because a prior session found the intermediate shapefile missing from
`/tmp` and, not having read the script closely enough, reported the source
as unrecoverable. It is not. Nothing needs to be reconstructed from memory.

**To rebuild:**

```
node tools/prep-streets-geo.mjs
```

**What that does, so a skim of this file is enough without opening the
script:**

1. Downloads the City of Chicago "Major Streets" dataset as a shapefile ZIP:
   - Portal page: https://data.cityofchicago.org/d/ueqs-5wr6
   - Resource id: `ueqs-5wr6`
   - Download URL: `https://data.cityofchicago.org/download/ueqs-5wr6/application/zip`
   - The script skips the download if `/tmp/major-streets/Major_Streets.shp`
     already exists, which is why it looked "gone" — that path is in `/tmp`
     and does not survive a container restart. It re-fetches on the next run.
2. Unzips to `/tmp/major-streets/` and reads `Major_Streets.dbf` (attributes,
   including the street name) and `Major_Streets.shp` (PolyLine geometry,
   binary-parsed with no external dependency).
3. Filters to the named arterials in the `WANTED` map inside the script
   (Western, Ashland, Halsted, Cicero, Pulaski, Kedzie, Madison, North,
   Belmont, Irving Park, Devon, Roosevelt, Cermak, 47th, 63rd, 79th, 95th).
4. Reprojects from the source CRS — NAD83 State Plane Illinois East (FIPS
   1201), US survey feet — to WGS84, with the inverse Transverse Mercator
   math inline in the script (no projection library).
5. Simplifies each line and writes `data/streets.geojson`.

**Why this dataset and not another:** the "Street Center Lines" dataset
(`6imu-meau`), which would be the more obvious source, is broken on the
portal — its SODA JSON endpoint returns rows with null geometry and empty
properties, and its GeoJSON export truncates. Both were confirmed broken
before `ueqs-5wr6` was adopted instead. If `6imu-meau` is ever fixed, it is
not a drop-in replacement: `WANTED`, the field names read from the DBF, and
the reprojection all assume the Major Streets schema.

**What is not in this dataset:** expressway mainlines (Kennedy, Eisenhower,
Dan Ryan, Stevenson, Edens). Searched and ruled out as of 2026-08-29: no
dedicated expressway geometry dataset exists on data.cityofchicago.org;
Traffic Tracker segments (`n4j6-wkkf`) only name expressway ramps, not the
mainline; Traffic Tracker regions (`t2qc-9pjd`) give neighborhood bounding
boxes, not lines. The Major Streets shapefile itself may or may not include
expressway segments under different name strings — that has not been
checked, since checking it means downloading the same zip this note is
about and no one had confirmed yet whether that was in scope for this pass.
